# 使用说明



## 功能

- 可拖动悬浮窗【暂停、最小化、关闭】
- 支持自动连播【列表播放】
- 拖动解锁
- 快速看完
- 自定义倍速(0.1~16x)
- 自动答题（含多选）

## 步骤

1. 打开视频播放界面
2. 打开开发人员工具【按下F12】
3. 粘贴代码
